# Root Snapshot Format (Standardized)
## File Naming: validation/evidence/NV-XX/validator_N_roots.txt
## File Format:
# AmunChain Root Snapshot
# Gate: NV-XX | Validator: validator-N | Height: <block height>
# Timestamp: <ISO 8601> | Baseline: 90f4993
Genesis Hash: <64-char hex>
State Root: <64-char hex>
Validator Set Root: <64-char hex>
History Root: <64-char hex>
Finality Root: <64-char hex>
