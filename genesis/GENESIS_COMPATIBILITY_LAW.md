# Genesis Compatibility Law

## Principle

Compatibility is determined by specification hash identity.

## Rules

### Identical Specification Hash
Systems with identical specification hashes are constitutionally identical.
They are the same civilization.

### Different Specification Hash
Systems with different specification hashes are different civilizations.
They require federation semantics for interoperability.

### Lineage Verification
All states must prove lineage to the genesis hash.
Lineage is verified through:
- Specification hash chain
- Replay equivalence proofs
- Freeze certificate validation

### Constitutional Amendments
Amendments that change the specification hash create a new
constitutional identity within the same lineage.

## Federation Prerequisites

Federation between civilizations requires:
- Mutual lineage verification
- Constitutional compatibility check
- Treaty semantics agreement
- Replay boundary definition

## Invariant

The genesis hash is the source of all constitutional authority.
