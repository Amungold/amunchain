Overview
--------
N120 adds a Merkle root over the deterministic slashing ledger,
enabling the root to be committed in block headers for consensus
verification.  The root is order-sensitive (respects execution
order) and uses blake3 for leaf and branch hashing.

What is included
----------------
N120.1   Merkle tree over ExecutedSlash history
         - Empty ledger → zero root
         - Single leaf deterministic
         - Order-sensitive: (A,B) ≠ (B,A)
         - Larger trees deterministic
