Overview
--------
N113 eliminates the temporary 32-byte → 48-byte zero-padding bridge
introduced in N110.1b.  ValidatorIdentityRegistry is now the sole
source of public key resolution inside RealStakingExecutor.

Before N113:
    validator_id → zero-padding → PublicKey

After N113:
    validator_id → ValidatorIdentityRegistry → PublicKey
    (unregistered validators are rejected)

What is included
----------------
N113.1   ValidatorIdentity struct + ValidatorIdentityRegistry
N113.2   RealStakingExecutor uses identity registry for lookup
N113.2b  Zero-padding fallback removed from production path;
         unregistered validators are rejected with an error
