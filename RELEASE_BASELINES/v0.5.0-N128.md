Overview
--------
N128 completes the transition from boolean constitutional checks to
cryptographically auditable evidence records. Every constitutional
law is now backed by structured, hash-verifiable evidence.

Before N128:
    review_block(height, true, true, true, ...)

After N128:
    ConstitutionalEvidenceRecord with SignatureEvidence,
    DoubleSpendEvidence, ReplayEvidence, GovernanceEvidence
    → evidence_hash for tamper detection

What is included
----------------
N127A    ConstitutionalEvidence interface + adapters
N127B    LiveValidator wired to ConstitutionalEvidence
N127C    Evidence source wiring with documented provenance
N127D    Direct Evidence Providers (Execution, Replay, Governance, QC)
N128     Evidence Records (Signature, DoubleSpend, Replay, Governance)
         + ConstitutionalEvidenceRecord with tamper-proof evidence_hash
