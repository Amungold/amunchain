Overview
--------
N121 elevates the slashing ledger from a sidecar structure to a
first-class consensus state component with fraud proofs,
deterministic replay, Merkle inclusion proofs, snapshot
commitment, and a historical audit layer.

What is included
----------------
N121.1   SlashingState — wraps ledger with auto-updating root
N121.2   Deterministic replay — 3 nodes, same events, same root
N121.3   Fraud proof engine — SlashingFraudProof creation + verification
N121.4   Merkle inclusion proofs — verify slash exists without full ledger
N121.5   Snapshot commitment — root survives state reconstruction
N121.6   Historical audit layer — query by validator, total count
