Overview
--------
N120 completes the slashing ledger's transition from local state to
consensus-committed state.

N120.1-3 built the Merkle tree, committed the root into Block headers
and FinalizedChainRecord, and provided the verification API.

N120.4 wires the root computation into the LiveValidator so that
every block produced by a proposer carries the correct slashing_root
computed from the local SlashingLedger. The block_hash includes
slashing_root, making it consensus-binding.

The verify_slashing_root() API is available for validators to
recompute and reject mismatched blocks. Full consensus-path
enforcement (rejecting blocks before voting) requires further
integration into the block reception path, which is deferred to a
future phase when non-proposer block deserialization is implemented.
