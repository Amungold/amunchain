Overview
--------
N118 completes the slashing execution pipeline by adding a finality
gate and enforcing multi-signer quorum verification as the only
path to stake reduction.

Before N118, slashing could be triggered directly via try_slash().
After N118, slashing requires:
  1. Certificate finality (cert_height <= finalized_height)
  2. Valid certificate signature
  3. Multi-signer quorum reached

Architecture (Complete Pipeline)
---------------------------------
Misbehavior Detected
  -> EvidenceRecord stored
  -> MisbehaviorRegistry scores
  -> SlashingCertificate created
  -> Certificate signed (Ed25519)
  -> MultiSignerCertificate with M-of-N quorum
  -> Certificate propagated via gossip
  -> Block inclusion + consensus verification
  -> Block finality reached (QC)
  -> execute_after_finality() gated
  -> ValidatorRegistry.slash()
  -> Stake reduced
