Overview
--------
N117 eliminates non-determinism from the constitutional simulation
engine (amun-constitutional-sim).  Before N117, recalibrated_tests
would fail intermittently due to random thread_rng() calls
producing different results across runs.

After N117, all simulation functions use StdRng::seed_from_u64(42),
making every simulation run identically reproducible.  The
recalibrated_tests pass 50/50 consecutive runs.

What is included
----------------
N117.1   random_seed field added to ExperimentalProtocol
N117.2   All thread_rng() calls replaced with StdRng::seed_from_u64(42)
N117.3   recalibrated_tests verified 50/50 consecutive passes
N117.4   All existing simulation tests pass without modification
