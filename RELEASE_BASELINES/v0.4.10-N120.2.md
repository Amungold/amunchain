Overview
--------
N120.2 commits the slashing Merkle root into the Block struct and
FinalizedChainRecord, making it part of the consensus state rather
than a local-only data structure.

Every block hash now includes slashing_root.  The root survives
encode/decode roundtrip through the chain store.

What is included
----------------
N120.1   Merkle tree over ExecutedSlash history (7 tests)
N120.2   slashing_root in Block + FinalizedChainRecord:
         - Block hash changes with slashing_root
         - Same root = same hash
         - Different roots = different hashes
         - Empty root allowed
         - Record roundtrip preserves root
         (6 tests)
