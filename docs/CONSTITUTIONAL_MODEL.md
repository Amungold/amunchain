# Constitutional Model

## Overview

The constitution is executable authority.

It is not documentation.
It is not convention.
It is not social consensus.

The constitution defines reality.

# Constitutional Drift

Drift occurs when semantics silently diverge.

Examples:

- serialization mutation
- replay mutation
- invariant weakening

AmunChain treats drift as civilization divergence.
