# AmunChain RFC Process

1. Proposal: Submit RFC as a pull request
2. Discussion: Community review
3. Revision: Author revises based on feedback
4. Decision: Maintainers accept or reject
5. Implementation: Accepted RFCs SHALL be implemented
6. Compliance: All RFCs SHALL conform to the Constitution
