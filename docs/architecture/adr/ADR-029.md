# ADR-029: State Commitment V2

Status: Design Complete — Ready for Implementation

Supersedes: Flat State Root Hash
Baseline: Commitment Layer V1

------------------------------------------------------------------------------

# Motivation

The current state_root is deterministic and cryptographically secure but it is
computed as a flat hash over the AccountStore.

This guarantees deterministic execution but cannot produce cryptographic proofs
required for:

- Light Clients
- Stateless Verification
- Cross-chain Verification
- Account Inclusion Proofs
- Account Non-Inclusion Proofs

Therefore State Commitment V2 introduces a Sparse Merkle Tree while preserving
all deterministic properties of the current implementation.
