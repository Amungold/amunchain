# AmunChain Constitutional RFC System

## Purpose
Any change to the Dependency Constitution, layer assignments, or architectural
laws MUST go through the RFC process.

## Process
1. Create a new RFC in `docs/rfcs/NNNN-title.md`
2. RFC MUST include: Motivation, Proposed Change, Migration Plan, Rollback Plan
3. RFC MUST be reviewed and accepted before implementation
4. After acceptance, update the Constitution and fingerprint

## RFC States
- **Draft** — under discussion
- **Accepted** — approved for implementation
- **Implemented** — deployed with fingerprint update
- **Rejected** — declined with reason
- **Superseded** — replaced by newer RFC
