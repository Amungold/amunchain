# AMUN DESIGN PLATFORM

# CODE OF CONDUCT

Version: 1.0

Status: FROZEN

Effective Date: 2026-07-01

---

# PURPOSE

This Code of Conduct defines the expected
behavior of every contributor,
maintainer,
reviewer,
architect,
and community member.

Our objective is to maintain a professional,
respectful,
inclusive,
and technically focused community.

---

# OUR VALUES

We value:

- Respect
- Professionalism
- Integrity
- Transparency
- Collaboration
- Technical Excellence

Every interaction SHALL reflect
these values.

---

# EXPECTED BEHAVIOR

Contributors are expected to:

- Be respectful
- Be constructive
- Be patient
- Accept technical feedback
- Explain decisions clearly
- Help other contributors
- Keep discussions professional

Technical merit SHALL always
take precedence over personal opinion.

---

# UNACCEPTABLE BEHAVIOR

The following behaviors are prohibited:

- Personal attacks
- Harassment
- Discrimination
- Hate speech
- Threats
- Trolling
- Intimidation
- Deliberate misinformation
- Abusive language
- Public humiliation

These behaviors are incompatible
with the project.

---

# TECHNICAL DISCUSSIONS

Architecture discussions SHALL be based on:

- Evidence
- Benchmarks
- Documentation
- Standards
- ADRs

Personal preference alone
is not sufficient justification.

---

# REVIEW CULTURE

Code reviews SHALL focus on:

- Code quality
- Architecture
- Security
- Performance
- Accessibility
- Documentation

Reviews SHALL NEVER become personal.

---

# COMMUNICATION

Contributors SHOULD:

- Write clearly
- Be concise
- Ask questions respectfully
- Assume good intentions
- Welcome constructive criticism

---

# DECISION MAKING

When disagreements occur,
the following order SHALL apply:

1. CONSTITUTION.md

2. GOVERNANCE.md

3. ARCHITECTURE.md

4. ADR Documents

5. Maintainer Decision

6. Chief Architect Decision

---

# REPORTING

Violations MAY be reported
to the project maintainers.

Reports SHOULD include:

- Description
- Evidence
- Context
- Impact

Reports SHALL be handled
confidentially whenever possible.

---

# ENFORCEMENT

Possible actions include:

- Warning

- Temporary restriction

- Removal from discussions

- Revocation of repository access

- Permanent exclusion

Actions SHALL be proportional
to the severity of the violation.

---

# SCOPE

This Code of Conduct applies to:

- Source Code
- Documentation
- Issues
- Pull Requests
- Discussions
- Reviews
- Official Communication
- Community Spaces

---

# PROFESSIONALISM

The Amun Design Platform is intended
to be an enterprise-grade project.

Every contributor represents
the quality and reputation
of the platform.

Professional behavior is expected
at all times.
