# Cross Civilization Compatibility

## Compatibility Model

Compatibility is determined constitutionally. Not politically. Not socially. Not operationally.

---

## Compatibility Levels

| Level | Meaning |
|---|---|
| Identical | Same specification hash |
| Compatible | Different hashes but treaty-compatible |
| Restricted | Limited interoperability |
| Foreign | No compatibility |
| Hostile | Explicit incompatibility |

---

## Identical Civilizations

If two civilizations produce the same specification hash:
- they are constitutionally identical
- replay equivalence must hold
- federation is implicit

---

## Compatible Civilizations

Compatible civilizations:
- preserve sovereign semantics
- negotiate replay boundaries
- maintain treaty compatibility

---

## Foreign Civilizations

Foreign civilizations:
- possess unrelated constitutional semantics
- cannot assume replay equivalence
- require explicit federation treaties

---

## Compatibility Verification

Verification requires:
- specification hash analysis
- replay verification
- treaty analysis
- lineage verification

---

## Invariant

Semantic equivalence may never be assumed without constitutional proof.
